Papasaurios — Salchipapería

Proyecto final del tecnólogo: tienda de comida rápida (salchipapas, hamburguesas, alitas) con 4 perfiles — cliente, cocina, repartidor y administrador. El cliente genera el pedido, pasa a cocina donde se prepara y se marca como listo, luego el repartidor lo recoge y lo entrega, todo bajo el control del panel de administrador. Backend en Java desplegado con Docker en Railway, base de datos MySQL y geolocalización, más una app móvil en Flutter que consume la misma API.
